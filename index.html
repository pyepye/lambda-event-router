🔀 Multi-source routing

Combine routers from different AWS services in a single Lambda handler.

🛡️ Type-safe routing

Full TypeScript support, with handler types inferred from the schemas and filters on the route.

🎛️ Declarative filters

Route events by ARN, eventType, topic, bucket, event name, detail type, and custom filter functions.

🧱 25+ AWS services

Dedicated routers for SQS, SNS, EventBridge, DynamoDB Streams, S3, API Gateway, and many more.

✅ Schema validation

Built-in schema validation for request bodies, message attributes, path params, and more. Compatible with any Standard Schema compatible library.

🧪 Well tested

Clear and concise tests covering most code branches for each event type.

ts
// main handler
import { LambdaRouter } from '@lambda-event-router/base'
import { apiRouter } from './api'
import { sqsRouter } from './sqs'

const lambdaRouter = new LambdaRouter({
  routers: [apiRouter, sqsRouter],
})

export const handler = lambdaRouter.handler()
ts
import { createAPIGatewayRouter } from '@lambda-event-router/apigateway'

import { getOrder } from './getOrder'
import { createOrder, createOrderSchema } from './createOrder'

const apiRouter = createAPIGatewayRouter()

apiRouter.route({
  filter {
    method: 'GET',
    path: '/order/:id/',
  },
  handler: getOrder,
})

apiRouter.route({
  filter {
    method: 'POST',
    path: '/order/:id/',
  },
  handler: createOrder,
  bodySchema: createOrderSchema,
})
ts
import { createSQSRouter } from '@lambda-event-router/sqs'

import { processOrder } from './order/process'
import { refundOrder } from './order/refund'

const sqsRouter = createSQSRouter()

sqsRouter.route({
  filter: { messageAttributes: { Type: ['ProcessOrder'] } },
  handler: processOrder,
})

sqsRouter.route({
  filter: { messageAttributes: { Type: ['RefundOrder'] } },
  handler: refundOrder,
})
