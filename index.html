LatcherType-safe event routing for AWS Lambda

One handler, any event source. Route API Gateway, SQS, DynamoDB, S3 and more to the right code.

Get Started
GitHub

🔀 Multi-source routing

Combine matchers from different AWS services in a single Lambda handler.

🛡️ Type-safe routing

Full TypeScript support, with handler types inferred from the schemas and filters on the route.

🎛️ Declarative filters

Route events by ARN, eventType, topic, bucket, event name, detail type, and custom filter functions.

🧱 25 AWS services

Dedicated matchers for SQS, SNS, EventBridge, DynamoDB Streams, S3, API Gateway, and many more.

✅ Schema validation

Built-in schema validation for request bodies, message attributes, path params, and more. Compatible with any Standard Schema compatible library.

🧪 Well tested

Clear and concise tests covering most code branches for each event type.

ts
// main handler
import { Latcher } from '@latcher/base'
import { apiMatcher } from './api'
import { sqsMatcher } from './sqs'

const latcher = new Latcher({
  matchers: [apiMatcher, sqsMatcher],
})

export const handler = latcher.handler()
ts
import { createAPIGatewayMatcher } from '@latcher/apigateway'

import { getOrder } from './getOrder'
import { createOrder, createOrderSchema } from './createOrder'

const apiMatcher = createAPIGatewayMatcher()

apiMatcher.route({
  filters: {
    method: 'GET',
    path: '/order/:id/',
  },
  handler: getOrder,
})

apiMatcher.route({
  filters: {
    method: 'POST',
    path: '/order/:id/',
  },
  handler: createOrder,
  bodySchema: createOrderSchema,
})
ts
import { createSQSMatcher } from '@latcher/sqs'

import { processOrder } from './order/process'
import { refundOrder } from './order/refund'

const sqsMatcher = createSQSMatcher()

sqsMatcher.route({
  filters: { messageAttributes: { Type: ['ProcessOrder'] } },
  handler: processOrder,
})

sqsMatcher.route({
  filters: { messageAttributes: { Type: ['RefundOrder'] } },
  handler: refundOrder,
})
