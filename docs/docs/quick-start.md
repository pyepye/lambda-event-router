# Quick Start


## Prerequisites

- AWS lambda
- NodeJS


## Install

```bash
npm install @lambda-event-router/[package]
```

```bash
npm install @lambda-event-router/apigateway @lambda-event-router/sqs
```


## Your first lambda

- Break down into steps
1. LambdaRouter
2. SQSHandler with 2 routes
3. SQSHandlers file with 2 handlers
