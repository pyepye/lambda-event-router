# Full examples

Each full example is an app you can deploy, chaining several AWS services through one flow. The
README in each one has the deploy steps, the commands that trigger it and a walk through the logs it
produces.

Each one uses a different deploy tool. `http-api-dynamodb-sqs` uses CDK,
`cognito-eventbridge-s3-avatars` uses AWS SAM.

They cover how several routers work together in one codebase, which the service examples do not.
